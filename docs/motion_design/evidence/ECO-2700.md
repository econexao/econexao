## 4. Inventário Explícito de Falhas e Inconsistências Preexistentes

Durante a auditoria read-only da base, foram catalogadas 10 inconsistências que **não devem ser mascaradas** e que servem de salvaguarda para as próximas tasks:

1. **[F1] Pulso CSS infinito embutido no marcador de seleção (`MapAdapter.web.tsx`):** Contém `animation:pulse 2s infinite;` sem keyframes definidos e contrariando a regra de não manter pulso infinito. *(Será corrigido na ECO-2702)*.
2. **[F2] Duplicação de código no Card Selecionado (`MapAdapter.web.tsx` vs `SelectedPinCard.tsx`):** A Web renderiza string HTML crua dentro do Leaflet `divIcon`, enquanto o nativo usa o componente React `SelectedPinCard`.
3. **[F3] Propriedade CSS Web em StyleSheet Native (`MapAdapter.native.tsx`):** Uso de `filter: 'drop-shadow...' as any` na linha 258, que não possui efeito em plataformas nativas (Android/iOS).
4. **[F4] Desmontagem imediata sem transição de saída (`AccessibleModal.web.tsx`):** Linha 130 retorna `null` imediatamente quando `!visible`, impedindo a execução de animações de saída (fade/slide) na Web sem suporte a presença. *(Foco da ECO-2706)*.
5. **[F5] Seletor de Origem contorna `AccessibleModal` (`OriginSelector.tsx`):** Utiliza `<Modal>` nativo diretamente na Web em vez do `AccessibleModal` padronizado, contornando o portal no DOM e a gestão de inert/foco.
6. **[F6] Disputa de overlays na Web (`app/route/[routeId]/map.tsx`):** Clicar em um pin abre simultaneamente o popup card do Leaflet e o bottom sheet modal no desktop.
7. **[F7] Galerias horizontais sem botões acessíveis (`RouteGallery.tsx` e `app/actor/[actorId].tsx`):** Não possuem botões "Anterior" / "Próximo" para navegação por teclado/clique, dependendo exclusivamente de gesto de arrasto. *(Foco da ECO-2704)*.
8. **[F8] Layout Shift no carregamento de fotos Google (`GooglePlacePhoto.tsx`):** A transição de loading (`minHeight: 120`) para a imagem renderizada com `aspectRatio: 4/3` gera salto de layout.
9. **[F9] Ausência prévia de cobertura de testes para a Rota do Pedral:** Não havia fixtures ou testes frontend validando as 4 origens oficiais restauradas na migration `20260917160415`. *(Coberto pelos novos testes desta task)*.
10. **[F10] Ausência prévia de teste de jornada contínua integrada:** Todos os testes E2E anteriores navegavam diretamente via URL isolada. *(Coberto pelo novo teste `eco2700-motion-baseline.spec.ts`)*.
