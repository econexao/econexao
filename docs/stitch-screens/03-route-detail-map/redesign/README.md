# Redesign — detalhes da rota

Referência visual mais recente da tela de detalhes da rota Pindobal.

## Arquivos

- `screen.png`: captura completa da proposta.
- `code.html`: protótipo HTML exportado pelo Stitch.
- `DESIGN.md`: tokens e diretrizes visuais associados ao protótipo.
- `gallery/`: imagens locais usadas como referência para a galeria da rota.

O material original permanece no diretório pai para comparação. Este protótipo é uma
referência de design e não substitui os contratos, critérios de aceite ou o código do
aplicativo.
