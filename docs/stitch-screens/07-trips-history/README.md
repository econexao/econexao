# Redesign — histórico de viagens

Referência visual fornecida pelo owner em 15/09/2026 para a tela
`/(tabs)/(profile)/trips`.

## Arquivos

- `screen.png`: captura completa da proposta.
- `code.html`: protótipo HTML exportado pelo Google Stitch.
- `DESIGN.md`: tokens e diretrizes visuais associados ao protótipo.

O protótipo orienta composição, hierarquia, cores e espaçamento. A implementação
mantém os campos do contrato `TripSchema`, os estados de consulta e as transições
reais de pausar, retomar e finalizar; textos ou dados ilustrativos que não existem
no contrato não são inventados em runtime.
